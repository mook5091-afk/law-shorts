# 캐릭터 자산

노동 판례 숏폼에 등장하는 3인방의 캐릭터 시트.

## 파일 넣는 법

`characters.json`의 각 캐릭터 `canva_url`을 열어 **원본(2720×1536)** 을 내려받은 뒤,
같은 폴더에 `file` 값과 같은 이름으로 저장한다.

| 캐릭터 | 저장할 파일명 |
|---|---|
| 김변 (변호사) | `lawyer_sheet.png` |
| 박씨 (노동자) | `worker_sheet.png` |
| 최사장 (사장) | `boss_sheet.png` |

## 패널 좌표

각 시트는 2720×1536, 가로 3등분이다.

| 패널 | x 범위 | 용도 |
|---|---|---|
| 전신 | 0 ~ 906 | 전체 장면 |
| 상반신 | 906 ~ 1813 | 대화 장면 |
| 얼굴 | 1813 ~ 2720 | 리액션·클로즈업 |

## 재생성 규칙

캐릭터를 다시 뽑을 때는 `style_lock` 문구를 **그대로 앞에 붙이고**
`prompt` 값만 바꾼다. 통일성이 깨지는 주된 원인은 style_lock 생략이다.

기존 캐릭터의 표정만 바꿀 때는 그 캐릭터의 이미지를 레퍼런스로 넣고
"같은 캐릭터, 표정만 변경"으로 요청한다.
